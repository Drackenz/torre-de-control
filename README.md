# Torre de Control

«Ordeno los aterrizajes de avionetas en un aeropuerto chico para que ninguna se quede sin combustible.»

## 1. Nombre y frase

Torre de Control. «Ordeno los aterrizajes de avionetas en un aeropuerto chico para que ninguna se quede sin combustible.»

## 2. Qué hace y cómo se usa

Ordená los aterrizajes de las avionetas antes de que se queden sin combustible.
Elegí una avioneta con las flechas o tocándola; aterrizá, hacela circular o desvíala.
Atendé las 8 avionetas con como máximo un desvío.

## 3. Enlace para abrirlo

[Abrir Torre de Control en este equipo](http://localhost:5173/) después de iniciar el servidor local.

[Abrir el repositorio del proyecto](https://github.com/Drackenz/torre-de-control).

## 4. Cómo correrlo en otra máquina

Requisitos: tener Node.js y npm instalados.

```sh
npm install
npm run dev
```

Abrí en el navegador la dirección que indique Vite, normalmente `http://localhost:5173/`.
